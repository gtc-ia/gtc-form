# Консолидация авторизации и чата на `https://app.gtstor.com`

## Предпосылки
- Сейчас регистрации происходят на `/auth`, а чат доступен на `/chat`.
- Разделение площадок приводит к рискам с куками и CORS, особенно при переходах через превью-домен Vercel.

## Предложение
Сделать `/chat` единой точкой входа: страница отображает состояние пользователя, предлагает логин/регистрацию и после успешной аутентификации открывает чат без междоменных редиректов.

## Ключевые принципы
1. **Один домен и одна сессия.** Все формы и API обращаются к `app.gtstor.com`, куки с доменом `gtstor.com`, `SameSite=Lax`, `Path=/` (или `/auth` при проксировании через тот же хост).
2. **Фронтенд без двойных редиректов.** Отказ от переходов на Vercel; все маршруты (`/auth`, `/chat`) обрабатываются на GTC1.
3. **Прозрачный бэкенд.** `gtc-auth` остаётся сервисом авторизации, но вызывается через обратный прокси `app.gtstor.com/auth/*`.

## Минимальный план миграции
- Включить фронтенд-роутинг для `/chat` c модулями регистрации/логина (UI reuse из `/auth`).
- Обновить конфигурацию прокси (nginx/agent) так, чтобы `/auth/*` обслуживался через `gtc-auth` на том же домене.
- Перепроверить переменные окружения на GTC1: `AUTH_COOKIE_DOMAIN=gtstor.com`, `APP_BASE_URL=https://app.gtstor.com`, `CHAT_REDIRECT_PATH=/chat/`.
- Выключить публичные редиректы на Vercel-превью, оставить его только для внутренних проверок без привязки к auth.

## Ожидаемый эффект
- Снижение отказов на `/auth/finish` из-за отсутствия куки.
- Единая точка поддержки и мониторинга (health-check для `/auth/finish` и `/chat`).
- Упрощение SLA: один домен, одно TLS, меньше кросс-доменных настроек.

## Риски и меры контроля
- Нагрузочные пики на GTC1: добавить autoscaling или горизонтальный балансировщик, если потребуется.
- Кэширование статики: убедиться, что CDN/Cloudflare обновлены после миграции.
- Логирование: включить согласованные логи для `gtc-auth` и фронтенда, чтобы отслеживать входы/перенаправления.

## Следующие шаги
- Подтвердить готовность фронтенда `/chat` к отображению форм регистрации/логина.
- Обновить конфигурацию nginx/agent и перезагрузить сервисы.
- Проверить сценарий: новый пользователь -> регистрация -> `/auth/finish` -> чат на `app.gtstor.com/chat` без внешних доменов.
